# Ilmaisia API:ja projekteihin

> Lähde: ulkoinen materiaali (tallennettu sosiaalisesta mediasta), ei sivuston omaa sisältöä.

Kokoelma ilmaisia API-rajapintoja, joita voi käyttää harjoitusprojekteissa staattisten sivujen sijaan – näin portfolioon saa oikeaa, dynaamista dataa.

## API-lista

| # | API | Kuvaus | Osoite |
|---|-----|--------|--------|
| 1 | JSONPlaceholder | Väärennetty REST API testaukseen ja prototyyppeihin | https://jsonplaceholder.typicode.com |
| 2 | DummyJSON | Tuotteita, käyttäjiä, postauksia ja muuta testidataa | https://dummyjson.com |
| 3 | OpenWeather API | Reaaliaikainen sää- ja ennustedata | https://openweathermap.org/api |
| 4 | REST Countries API | Maiden tiedot, liput, kielet ja muu | https://restcountries.com/v3.1 |
| 5 | GitHub API | Pääsy GitHub-repoihin, käyttäjiin ja muuhun | https://api.github.com |
| 6 | PokeAPI | Pokémon-dataa hauskoihin ja luoviin projekteihin | https://pokeapi.co/api/v2 |
| 7 | TMDB API | Elokuvat, TV-sarjat, näyttelijät ja arvostelut | https://api.themoviedb.org/3 |
| 8 | Unsplash API | Laadukkaita ilmaisia kuvia projekteihin | https://api.unsplash.com |
| 9 | CoinGecko API | Kryptovaluuttojen hinnat, kaaviot ja markkinadata | https://api.coingecko.com/api/v3 |
| 10 | News API | Tuoreimmat uutisotsikot ympäri maailmaa | https://newsapi.org/v2 |
| 11 | Random User API | Satunnaisten käyttäjäprofiilien ja avatarien generointi | https://randomuser.me/api |
| 12 | Quotable API | Inspiroivia ja kuuluisia sitaatteja | https://api.quotable.io |
| 13 | NASA API | Avaruus-, tähtitiede- ja missiodataa | https://api.nasa.gov |
| 14 | Open Library API | Kirjat, kirjailijat ja kirjastotiedot | https://openlibrary.org/dev/docs/api |
| 15 | Cat Facts API | Satunnaisia kissafaktoja hauskoihin projekteihin | https://catfact.ninja/fact |
| 16 | ExchangeRate API | Reaaliaikaiset valuuttakurssit | https://api.exchangerate.host |
| 17 | Calendarific API | Kalenteri-, pyhäpäivä- ja tapahtumatietoa | https://calendarific.com/api |
| 18 | LibreTranslate API | Ilmainen ja avoimen lähdekoodin käännös-API | https://libretranslate.com |
| 19 | API Ninjas | Useita API:ja samassa paikassa (faktat, vitsit ym.) | https://api-ninjas.com/api |
| 20 | ToDo List API | Yksinkertainen ja ilmainen REST API tehtävälistasovelluksiin | https://dummyjson.com/todos |
| 21 | Color API | Värien nimet, koodit ja paletit | https://www.thecolorapi.com |
| 22 | DataUSA API | Yhdysvaltain julkista dataa taloudesta, työpaikoista ja koulutuksesta | https://datausa.io/api |
| 23 | IP Geolocation API | Sijaintitiedot IP-osoitteen perusteella | https://ipapi.co/json |
| 24 | Dictionary API | Sanojen merkitykset, määritelmät ja esimerkit | https://dictionaryapi.dev |
| 25 | Official Joke API | Satunnaisia vitsejä huumorin lisäämiseen sovellukseen | https://official-joke-api.appspot.com |

> Vinkki: Jokaisen frontend-kehittäjän kannattaa kirjanmerkitä nämä ilmaiset API:t projekteja varten.
