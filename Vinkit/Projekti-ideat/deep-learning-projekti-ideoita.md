# Deep learning -projekti-ideoita (keskitaso)

> Lähde: ulkoinen materiaali (tallennettu sosiaalisesta mediasta), ei sivuston omaa sisältöä.

Keskitason syväoppimisprojekteja, painottuen konenäköön ja kuvankäsittelyyn.

## Intermediate level

- Käsinkirjoitettujen numeroiden OCR syväoppimisella (Deep Learning OCR of Handwritten Digits)
- Käsinkirjoitettujen numeroiden tunnistus (Handwritten Digit Recognition)
- Tekstin tunnistus ja poiminta (Text Detection and Extraction)
- Kasvomaskin tunnistus (FaceMask Detection)
- Koirarodun luokittelu (Dog Breed Classification)
- Kukkien tunnistus (Flower Recognition)
- Kissojen ja koirien luokittelu CNN:llä (Cat & Dog Classification using CNN)
- Liikennemerkkien tunnistus (Traffic Signs Recognition)
- CIFAR-10-kuvien luokittelu (CIFAR-10 Image Classification)
- Monikluokkainen kuvien luokittelu (Multiclass Image Classification)
- Kuvatekstin generointi (Image Caption Generator)
- Kuvan sarjakuvamaistaminen (Cartooning an Image)
- Kuvan sarjakuvamaistaja-projekti (Image Cartoonifier Project)
- Kasvojen laskeminen kuvasta (Count Number of Faces)
- Objektien laskeminen kuvasta (Count Number of Object)
- Iän tunnistus (Age Detection)
