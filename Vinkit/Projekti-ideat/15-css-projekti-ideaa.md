# 15 CSS-projekti-ideaa

> Lähde: ulkoinen materiaali (tallennettu sosiaalisesta mediasta), ei sivuston omaa sisältöä.

Rakenna todellisen maailman CSS-taitoja käytännön projektien kautta: 5 aloittelijatason, 5 keskitason ja 5 edistynyttä projektia.

## Aloittelijaprojektit (Beginner)

1. **Personal Profile Card** – henkilökohtainen profiilikortti (esim. nimi, ammattinimike, sosiaalisen median linkit).
2. **Responsive Navigation Bar** – responsiivinen navigaatiopalkki.
3. **Landing Page Hero Section** – laskeutumissivun hero-osio.
4. **Pricing Cards Layout** – hinnoittelukorttien asettelu (esim. Basic/Pro/Premium-tasot).
5. **CSS Image Gallery** – CSS-pohjainen kuvagalleria.

## Keskitason projektit (Intermediate)

1. **Responsive Portfolio Website** – responsiivinen portfoliosivusto (esittelyteksti, "View Work" -painike, kuvagalleria).
2. **Dashboard UI Design** – dashboard-käyttöliittymä (esim. kävijät, tilaukset, liikevaihto -tilastokortit, liikennekaavio, top-maat-kaavio).
3. **Animated Login Form** – animoitu kirjautumislomake ("Welcome Back!").
4. **Product Card with Hover Effects** – tuotekortti hover-efekteillä (esim. tuotekuva, hinta, arvostelu).
5. **Multi-Section Company Website** – monisivuinen yrityssivusto.

## Edistyneet projektit (Advanced)

1. **Netflix Landing Page Clone** – Netflix-tyylinen laskeutumissivun kopio (sisäänkirjautuminen, "Unlimited movies, TV shows, and more.", sähköpostikenttä, suosituimmat-rivi).
2. **CSS-Only Accordion System** – pelkällä CSS:llä toteutettu haitari (esim. UKK-osio: "What is CSS?", "How does it work?", "Can I use it in projects?", "Is CSS hard to learn?").
3. **Advanced Responsive Admin Panel** – edistynyt responsiivinen admin-paneeli.
4. **Interactive CSS Animation Showcase** – interaktiivinen CSS-animaatioesittely (esim. `.btn` hover-siirtymä `transform: translateY(-3px)`).
5. **Modern SaaS Website Design** – moderni SaaS-sivustosuunnittelu ("The all-in-one platform for your business").

## Esimerkkikoodinpätkiä

### Container-esimerkki (grid)

```css
.container {
  display: grid;
  gap: 20px;
  padding: 20px;
  border-radius: 12px;
  background: #f8fafc;
}
```

### Napin tyylit ja hover-animaatio

```css
.btn {
  padding: 12px 24px;
  background: linear-gradient(135deg, #667eea, #764ba2);
  border: none;
  border-radius: 8px;
  color: #fff;
  transition: all 0.3s ease;
}

.btn:hover {
  transform: translateY(-3px);
}
```
