# Aloittelijaystävälliset API-projektit

> Lähde: ulkoinen materiaali (tallennettu sosiaalisesta mediasta), ei sivuston omaa sisältöä.

"20 API-projektia = työelämävalmiit backend-taidot" – sarjan ensimmäinen osa: aloittelijaystävälliset projektit backend-taitojen rakentamiseen.

## 1. Weather API App (aloita tästä – helpoin)

- Hae sää kaupungin mukaan
- Lämpötila, kosteus, tuuli
- 5 päivän ennustenäkymä
- Automaattinen sijainnin tunnistus
- Sääikonit (aurinko, sade jne.)

## 2. Quote Generator

- Satunnaiset sitaatit
- Kategoriasuodatin
- Kopiointi/jako-painike

## 3. Currency Converter

- Muunna valuuttojen välillä
- Reaaliaikaiset vaihtokurssit
- Pudotusvalikko valuutan valintaan

## 4. News API

- Hae uusimmat uutiset
- Suodata kategorian mukaan
- Haku avainsanalla

## Vinkki

Valitse yksi, rakenna se, ja kehitä API-taitojasi askel askeleelta.
