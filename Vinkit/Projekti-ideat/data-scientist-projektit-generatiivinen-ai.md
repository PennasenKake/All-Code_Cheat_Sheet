# Data scientist -projekteja: generatiivinen AI

> Lähde: ulkoinen materiaali (tallennettu sosiaalisesta mediasta), ei sivuston omaa sisältöä.

Osa laajempaa "50 Data Scientist Project Ideas" -listaa (osa 5/10: Generative AI).

## Generative AI -projektit

- Build Your Own RAG System (PDF → Chunk → Embed → Retrieve → Generate) – oma RAG-järjestelmä: PDF pilkotaan paloihin, upotetaan (embed), haetaan relevantit palat ja generoidaan vastaus.
- Domain-Specific Chatbot using LLM + Vector DB – toimialakohtainen chatbot, joka yhdistää LLM:n ja vektoritietokannan.
- LLM Fine-Tuning (LoRA / PEFT) on Custom Dataset – LLM:n hienosäätö LoRA/PEFT-menetelmillä omalla datasetillä.
- AI Resume Reviewer using GPT + Scoring Logic – tekoälypohjainen CV:n arviointi GPT:llä ja pisteytyslogiikalla.
- Meeting Notes Summarizer with Structured Output – kokousmuistiinpanojen tiivistäjä, joka tuottaa jäsennellyn ulostulon.
- AI SQL Generator with Validation Layer – tekoälyllä toteutettu SQL-generaattori, jossa on validointikerros.
- LLM-Based Code Reviewer – LLM-pohjainen koodikatselmoija.
- Synthetic Data Generator using LLMs – synteettisen datan generointi LLM:illä.
- Automated Report Generator (Excel → Insight Narrative) – automaattinen raporttigeneraattori, joka muuttaa Excel-datan sanalliseksi analyysiksi.
- AI Tutor with Memory & Context Retention – tekoälyopettaja, joka muistaa aiemman keskustelukontekstin.
