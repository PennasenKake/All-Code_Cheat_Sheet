# Edistyneet API-projektit (ilmoitukset, rate limiting, haku, lokitus)

> Lähde: ulkoinen materiaali (tallennettu sosiaalisesta mediasta), ei sivuston omaa sisältöä.

"Level Up" -sarjan jatko-osa: edistyneet API-projektit backend-taitojen kehittämiseen.

## 13. Notification System API

- Sähköposti-ilmoitusten lähetys
- Push-ilmoitukset (FCM)
- Sovelluksen sisäinen ilmoitusjärjestelmä
- Merkitse luetuksi/lukemattomaksi

## 14. Rate Limiting API

- Rajoita pyyntöjä IP:n/käyttäjän mukaan
- Estä väärinkäyttö ja roskaposti
- Konfiguroitavat rajasäännöt
- Palauta 429-virhe retry-after-headerilla

## 15. Search API

- Täystekstihaku
- Suodattimet, järjestäminen ja sivutus
- Hakuehdotukset
- Osumien korostus tuloksissa

## 16. Logging & Monitoring API

- Kirjaa API-pyynnöt ja virheet
- Keskitetty lokitus (esim. Winston)
- Virheiden seuranta ja hälytykset
- Monitorointimetriikkojen rajapinta

## Vinkki

Rakenna oikeita projekteja. Ratkaise oikeita ongelmia. Tule oikeaksi kehittäjäksi.
