# Data scientist -projekteja: agenttinen AI

> Lähde: ulkoinen materiaali (tallennettu sosiaalisesta mediasta), ei sivuston omaa sisältöä.

Osa laajempaa "50 Data Scientist Project Ideas" -listaa (osa 6/10: Agentic AI).

## Agentic AI -projektit

- Multi-Agent Research Assistant (Planner + Researcher + Critic) – moniagenttinen tutkimusavustaja, jossa erilliset agentit suunnittelevat, tutkivat ja arvioivat tuloksia.
- Autonomous Data Analyst Agent (Upload CSV → Insights → Dashboard) – autonominen data-analyytikkoagentti: CSV ladataan, agentti tuottaa oivalluksia ja dashboardin.
- AI Job Application Agent (Resume Tailoring + JD Matching) – tekoälyagentti, joka räätälöi CV:n ja vertaa sitä työpaikkailmoitukseen.
- Web Browsing Agent with Tool Calling – verkkoa selaava agentti, joka käyttää työkalukutsuja (tool calling).
- Financial Portfolio Advisor Agent – sijoitussalkun neuvoja-agentti.
- AI DevOps Assistant (Logs → Root Cause → Fix Suggestion) – DevOps-avustaja, joka analysoi lokeja, löytää juurisyyn ja ehdottaa korjausta.
- Customer Support Agent with Escalation Logic – asiakastukiagentti, jossa on eskalointilogiikka.
- AI Personal Knowledge Base Agent – henkilökohtainen tietokanta-agentti.
- Automated Market Research Agent – automatisoitu markkinatutkimusagentti.
- Self-Improving Agent with Feedback Loop – itseään parantava agentti palautesilmukan avulla.
