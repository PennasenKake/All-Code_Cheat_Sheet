# Data scientist -projekteja: deep learning

> Lähde: ulkoinen materiaali (tallennettu sosiaalisesta mediasta), ei sivuston omaa sisältöä.

Osa laajempaa "50 Data Scientist Project Ideas" -listaa (osa 4/10: Deep Learning).

## Deep Learning -projektit

- Image Classification using CNN (Production-Ready) – kuvien luokittelu konvoluutioverkolla, tuotantovalmiina toteutuksena.
- Object Detection (YOLO / Faster R-CNN) – kohteiden tunnistus YOLO- tai Faster R-CNN -malleilla.
- NLP Text Classification with Transformers – tekstin luokittelu Transformer-malleilla.
- Resume Screening using BERT – työhakemusten seulonta BERT-mallilla.
- Speech-to-Text Model Fine-Tuning – puheentunnistusmallin hienosäätö.
- Chatbot with Intent Classification – chatbot, joka tunnistaa käyttäjän aikomuksen (intent).
- Sentiment Analysis using LSTM vs Transformers Comparison – sentimenttianalyysi, LSTM- ja Transformer-mallien vertailu.
- GAN for Image Generation – kuvien generointi GAN-verkolla.
- Autoencoder for Dimensionality Reduction – ulottuvuuksien vähentäminen autoenkooderilla.
- Multimodal Model (Image + Text Fusion) – multimodaalinen malli, joka yhdistää kuva- ja tekstidatan.
