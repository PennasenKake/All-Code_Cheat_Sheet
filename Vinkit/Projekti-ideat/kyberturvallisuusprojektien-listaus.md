# Kyberturvallisuusprojektien listaus

> Lähde: ulkoinen materiaali (tallennettu sosiaalisesta mediasta), ei sivuston omaa sisältöä.

Projekti-ideoita kyberturvallisuuden pariin.

## Puolustuspainotteiset (Defense-focused)

- Zero Trust Network Access (ZTNA) -toteutus
- Tekoälypohjainen uhkien tunnistusjärjestelmä (AI-Driven Threat Detection System)
- Lohkoketjupohjainen turvallinen dokumenttien jakaminen (Blockchain-based Secure Document Sharing)

## Hyökkäyspainotteiset (Offensive-focused)

- Web-sovellusten tunkeutumistestauskehys (Web Application Penetration Testing Framework)
- Pilviympäristön tietoturva-asennon hallintatyökalu (Cloud Security Posture Management, CSPM)
- Kiristyshaittaohjelmien analysointi ja purkutekniikat (Ransomware Analysis and Decryption Techniques)

## Yleiset

- Käyttäjän käyttäytymisen anomaliantunnistusjärjestelmä (User Behavior Anomaly Detection System)
- Kyberriskien arviointityökalu (Cyber Insurance Risk Assessment Tool)
- Yksityisyyttä suojaava koneoppimiskehys (Privacy-Preserving Machine Learning Framework)
