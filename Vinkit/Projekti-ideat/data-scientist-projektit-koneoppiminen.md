# Data scientist -projekti-ideoita: koneoppiminen

> Lähde: ulkoinen materiaali (tallennettu sosiaalisesta mediasta), ei sivuston omaa sisältöä.

Osa laajempaa "50 Data Scientist Project Ideas" -listaa (osa 2/10: Machine Learning). Hyviä portfolioprojekti-ideoita koneoppimisen osaamisen näyttämiseen.

## Machine Learning -projektit

- Customer Churn Prediction with Explainable AI – asiakaspoistuman ennustaminen selitettävän tekoälyn (esim. SHAP) avulla.
- Credit Risk Modeling with Feature Importance Analysis – luottoriskimallinnus ja ominaisuuksien tärkeysanalyysi.
- End-to-End MLOps Pipeline (Training → Deployment → Monitoring) – kokonainen MLOps-putki koulutuksesta julkaisuun ja seurantaan.
- Fraud Detection with Imbalanced Learning Techniques – petosten tunnistus epätasapainoisen datan menetelmillä.
- Demand Forecasting using Time Series + ML Hybrid – kysynnän ennustaminen aikasarja- ja koneoppimismenetelmien yhdistelmällä.
- Price Optimization using Regression + Elasticity Modeling – hinnoittelun optimointi regression ja hintajouston mallinnuksella.
- Customer Lifetime Value Prediction – asiakkaan elinkaariarvon ennustaminen.
- Lead Scoring Model for Sales Teams – liidien pisteytysmalli myyntitiimeille.
- Recommendation System (Collaborative + Content-Based Hybrid) – suositusjärjestelmä, joka yhdistää yhteistoiminnallisen ja sisältöpohjaisen suodatuksen.
- A/B Testing with Causal Inference – A/B-testaus kausaalipäättelyn menetelmin.
