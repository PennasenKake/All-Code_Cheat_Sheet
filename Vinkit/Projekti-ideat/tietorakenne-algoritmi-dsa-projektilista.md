# Tietorakenne- ja algoritmi (DSA) -projektilista

> Lähde: ulkoinen materiaali (tallennettu sosiaalisesta mediasta), ei sivuston omaa sisältöä.

60 DSA-projektia aloittelijasta edistyneeseen — tässä aloittelijan taso, jossa jokainen projekti harjoittaa tiettyä tietorakennetta tai algoritmia.

## Aloittelijan projektit

- Student Record System — käyttäen taulukkoja (Arrays)
- Contact Book — käyttäen linkitettyä listaa (Linked List)
- Undo/Redo Feature — käyttäen pinoa (Stack)
- Printer Queue Simulation
- Browser History Manager
- Music Playlist — käyttäen ympyrälinkitettyä listaa (Circular Linked List)
- Balanced Brackets Validator
- Railway Reservation System — jonopohjainen (Queue Based)
- Hospital Token System — jonopohjainen (Queue Based)
- Palindrome Checker — käyttäen kaksipäistä jonoa (Deque)
- Spell Checker — käyttäen hajautusta (Hashing)
- Leaderboard Ranking System
- Basic Library Management — käyttäen taulukkoja
- Parking Lot Management — käyttäen pinoa
- Online Exam System — monivalintakysymysten tallennus taulukkoon
- File Compression Simulation — käyttäen Huffman-koodausta
- Simple Text Editor — Undo/Redo pinon avulla
- Maze Solver — käyttäen leveyssuuntaista hakua (BFS)
- Phone Directory — käyttäen hajautustaulua (Hash Map)
- Bank Account System — käyttäen linkitettyä listaa
