# LLM vs RAG vs AI Agent vs Agentic AI -vertailu

> Lähde: ulkoinen materiaali (tallennettu sosiaalisesta mediasta), ei sivuston omaa sisältöä.

Tekoälyjärjestelmien älykkyyden kerrokset – neljä toisiaan täydentävää käsitettä.

## LLM (Large Language Model)

Perustaso, joka ymmärtää ja tuottaa kieltä.

- Instruction Following (ohjeiden noudattaminen)
- Knowledge recall (within training) – tietämyksen palauttaminen (koulutusdatasta)
- Prompt Engineering
- Few-shot/Zero-shot Learning
- Chain-of-Thought reasoning
- Attention Mechanism
- Tokenization
- Text Generation
- Conversational memory (short term)
- Natural Language Generation (NLG)
- Natural Language Understanding (NLU)
- Transformer Architecture
- Embedding Generation

## RAG (Retrieval Augmented Generation)

Lisää ulkoista tietoa vastausten tarkentamiseksi ja pohjustamiseksi.

- Embedding Models
- Similarity Scoring
- Document Chunking
- Context Injection
- Grounded Answer Generation
- Retrieval & execution pipeline
- Domain-Specific Text Calls
- Long-Term Context Memory
- Vector Search
- Custom knowledge base integration
- Query Reformulation
- Source Attribution
- Retrieval Pipelines
- Index Management
- Hybrid Search (dense & sparse)
- Metadata Filtering
- Prompt + Retrieval Fusion
- Knowledge-Grounded Responses

## AI Agent

Ryhtyy toimiin, käyttää työkaluja ja suorittaa tehtäviä.

- External data augmented action
- Query-Term-Planning
- Tool Use & API Calling
- Planning & Execution
- Task Decomposition
- ReAct Framework
- Code Execution
- Feedback Loops
- Task State Tracking
- File Access/Interaction
- Memory Integration (short + long term)

## Agentic AI

Orkestroi useita agentteja, sopeutuu ja tavoittelee monimutkaisia päämääriä autonomisesti.

- Context
- Reasoning
- Semantic understanding
- Hierarchical Task Execution
- Role Delegation / Modular Task Distribution
- Multi-Agent Collaboration
- Agent Orchestration
- ACP (Agent Communication Protocol)
- Agent Role Assignment
- Task Orchestration
- State Memory Propagation
- Autonomous Planning
- Long-Term Memory Sharing
- Feedback-driven adaptation
- MCP (Model Context Protocol)
- A2A Protocol (Agent-to-Agent)
- Autonomous Goal Planning
- Long-term Memory Management
- Role-Specific Agents
- Agent Lifecycle Management

## Yhteenveto

- **LLM:** perustaso, joka ymmärtää ja tuottaa kieltä.
- **RAG:** lisää ulkoista tietoa, jotta vastaukset ovat tarkempia ja pohjautuvat faktoihin.
- **AI Agent:** ryhtyy toimiin, käyttää työkaluja ja suorittaa tehtäviä.
- **Agentic AI:** orkestroi useita agentteja, sopeutuu ja tavoittelee monimutkaisia päämääriä autonomisesti.
