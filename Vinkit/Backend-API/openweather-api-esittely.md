# OpenWeather API -esittely

> Lähde: ulkoinen materiaali (tallennettu sosiaalisesta mediasta), ei sivuston omaa sisältöä.

Lyhyt esittely OpenWeather-rajapinnasta (openweathermap.org):

- Tarjoaa reaaliaikaista ja historiallista säädataa sovelluksiin.
- Käytetään sääennusteissa, dashboardeissa ja sijaintipohjaisissa sovelluksissa.

Kuvassa näkyvä esimerkkidashboard havainnollistaa tyypillistä käyttötapausta: käyttäjä hakee säätiedot kaupungin nimellä (esim. "London, GB"), ja näkyviin tulee nykyinen sää (lämpötila, pilvisyys, tuntuu kuin -lämpötila), tunneittainen ennuste sekä lisätietoja kuten tuulen nopeus, ilmankosteus, näkyvyys, ilmanpaine, UV-indeksi ja kastepiste. Tällaisen datan saa haettua OpenWeatherin REST-rajapinnasta API-avaimella (Get API Key) ja käytettäväksi omassa sovelluksessa, esimerkiksi sää-widgetissä tai sovelluksen taustapalvelussa.
