# Frontend-kehittäjän roadmap 2026

> Lähde: ulkoinen materiaali (tallennettu sosiaalisesta mediasta), ei sivuston omaa sisältöä.

Askel askeleelta -opas ammattimaiseksi frontend-kehittäjäksi.

## Oppimispolku

HTML5 → CSS3 → JavaScript → Git & GitHub → Tailwind CSS → TypeScript → React.js → Next.js → API:t → Auth → Deploy → Projektit

## 1. Web-perusteet

**HTML5:** semanttiset elementit, lomakkeet ja validointi, taulukot, multimedia, saavutettavuus (ARIA), SEO-perusteet.

**CSS3:** valitsimet ja spesifisyys, box-malli, flexbox, CSS grid, media queryt, animaatiot ja siirtymät, CSS-muuttujat.

## 2. JavaScript (ES6+)

Muuttujat, scope, hoisting, datatyypit, operaattorit, funktiot, arrow-funktiot, taulukot ja oliot, destrukturointi, spread, DOM-manipulaatio, eventit, promiset, async/await, modulit, virheenkäsittely.

## 3. Versionhallinta

**Git:** init, add, commit, push, branch, merge, rebase, stash.
**GitHub:** repositoriot, branchit, pull requestit, actions.

## 4. CSS-frameworkit

Tailwind CSS, Bootstrap, Material UI, shadcn/ui.

## 5. Build-työkalut ja paketinhallinta

npm, pnpm, yarn – paketinhallintaan. Vite, Webpack (perusteet), Babel.

## 6. TypeScript

Tyypit, rajapinnat (interfaces), funktiot, geneerit, TypeScript Reactin kanssa.

## 7. React.js

JSX, komponentit, propsit, state, useState, useEffect, hookit, lomakkeet, eventit, listat ja avaimet (keys), ehdollinen renderöinti, Context API, portaalit.

## 8. Next.js

App Router, tiedostopohjainen reititys, palvelin- ja asiakaskomponentit, API-reitit, dynaamiset reitit, layoutit, metadata & SEO, kuvien optimointi.

## 9. Tilanhallinta (State Management)

Context API (perus), Redux Toolkit (suositeltu), Zustand (kevyt).

## 10. API-integraatio

Fetch API, Axios, REST API:t, CRUD-operaatiot, GraphQL (perusteet), virheenkäsittely.

## 11. Autentikointi

JWT, OAuth, Firebase Authentication / Auth.js, suojatut reitit, RBAC.

## 12. Testaus

Jest, React Testing Library, Cypress / Playwright, yksikkö-, integraatio- ja E2E-testaus.

## 13. Suorituskyvyn optimointi

Lazy loading, code splitting, memoisointi (React.memo, useMemo), kuvien optimointi, Lighthouse, välimuistitus.

## 14. PWA ja Service Workerit

Service workerit, offline-tuki, web manifest, push-ilmoitukset.

## 15. Käyttöönotto (Deployment)

Vercel (suositeltu), Netlify, GitHub Pages, Firebase Hosting.

## Opittavat taidot

- Rakenna responsiivisia ja saavutettavia sivustoja
- Luo interaktiivisia käyttöliittymiä
- Työskentele API:en ja autentikoinnin kanssa
- Optimoi suorituskykyä
- Julkaise full-stack-sovelluksia

## Olennaiset työkalut

VS Code, Chrome DevTools, Postman, Figma, ESLint & Prettier, GitHub, Lighthouse.

## Projekti-ideoita

- **Aloittelija:** laskin, sää-sovellus, todo-sovellus, landing page
- **Keskitaso:** blogisivusto, dashboard, kulujenseuranta, elokuvasovellus, muistiinpanosovellus
- **Edistynyt:** verkkokauppa, LMS-dashboard, chat-sovellus, some-kloon, videostriimauspalvelu, projektinhallintatyökalu

## Parhaat käytännöt

Kirjoita puhdasta ja luettavaa koodia, noudata responsiivisen suunnittelun periaatteita, varmista saavutettavuus (WCAG), optimoi suorituskykyä, noudata SEO:n parhaita käytäntöjä, opi ja rakenna jatkuvasti.
