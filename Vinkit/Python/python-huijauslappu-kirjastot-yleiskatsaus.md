# Python-huijauslappusarja: keskeiset data- ja automaatiokirjastot

> Lähde: ulkoinen materiaali (tallennettu sosiaalisesta mediasta), ei sivuston omaa sisältöä.

Tämä on kansi/johdanto Frank Andraden Python-huijauslappusarjalle, joka kattaa seuraavat kirjastot ja aiheet:

- **Pandas** – datan käsittely ja analyysi
- **Numpy** – numeerinen laskenta ja taulukot
- **Sklearn (scikit-learn)** – koneoppiminen
- **Matplotlib** – datan visualisointi
- **Seaborn** – tilastollinen visualisointi
- **BS4 (BeautifulSoup)** – web scraping / HTML-jäsennys
- **Selenium** – selainautomaatio
- **Scrapy** – web-kaavintakehys (scraping framework)

Näiden kirjastojen tarkempi sisältö (koodiesimerkit) löytyy tämän kansion muista huijauslappu-tiedostoista: scikit-learn (mallin luonti, arviointi, viritys), Pandas, NumPy, Data Viz (Matplotlib/Seaborn) ja web scraping (BeautifulSoup, Selenium, Scrapy).
