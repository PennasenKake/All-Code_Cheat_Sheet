# Python-kirjastojen käyttötarkoitukset

> Lähde: ulkoinen materiaali (tallennettu sosiaalisesta mediasta), ei sivuston omaa sisältöä.

Yksi kieli, rajattomat mahdollisuudet — Python taipuu moneen käyttötarkoitukseen riippuen siitä, mitä kirjastoa sen kanssa käytetään.

- Python + **Pandas** = datan käsittely (data manipulation)
- Python + **TensorFlow** = syväoppiminen (deep learning)
- Python + **Matplotlib** = datan visualisointi
- Python + **Seaborn** = edistyneet kaaviot
- Python + **BeautifulSoup** = web-kaavinta (web scraping)
- Python + **Selenium** = selainautomaatio
- Python + **FastAPI** = suorituskykyiset API:t
- Python + **SQLAlchemy** = tietokantayhteydet
- Python + **Flask** = kevyet web-sovellukset
- Python + **Django** = skaalautuvat alustat
- Python + **Pygame** = pelikehitys
