# JavaScript-operaattorit

> Lähde: ulkoinen materiaali (tallennettu sosiaalisesta mediasta), ei sivuston omaa sisältöä.

Osa "30 Days JavaScript" -sarjaa, päivä 5: operaattorit — laskutoimitusten ja vertailujen suorittaminen.

## Mitä operaattorit ovat?

- Operaattorit suorittavat toimintoja arvoille ja muuttujille.
- Käytetään laskutoimituksiin ja vertailuihin.
- Olennaisia päätöksenteolle ja logiikalle.
- Auttavat datan muokkaamisessa ja päivittämisessä.

### Esimerkki

```javascript
10 + 5 = 15
5 > 3 = true
```

Arvo (10) + operaattori (+) + arvo (5) → tulos (15).

## Operaattorityypit

- **Math Operators:** `+  -  *  /`
- **Comparison Operators:** `==  >  <  <=  >=  !=`

## Yleiset JavaScript-operaattorit

### Aritmeettiset operaattorit (Arithmetic Operators)

- Käytetään laskutoimituksiin.
- Yhteen-, vähennys-, kerto- ja jakolasku.
- Palauttaa numeerisia tuloksia.

```javascript
10 + 5
10 - 5
10 * 5
10 / 5
```

### Sijoitusoperaattorit (Assignment Operators)

- Sijoittavat arvoja muuttujiin.
- Päivittävät olemassa olevia arvoja.
- Käytetään usein ohjelmissa.

```javascript
let x = 10;
x += 5;
```

### Vertailuoperaattorit (Comparison Operators)

- Vertaavat kahta arvoa.
- Palauttavat `true` tai `false`.
- Käytetään ehtolauseissa.

```javascript
10 > 5
10 == 10
5 !== 3
```

### Loogiset operaattorit (Logical Operators)

- Yhdistävät ehtoja.
- Toimivat totuusarvoilla (Boolean).
- Käytetään päätöksenteossa.

```javascript
true && true
true || false
!true
```

## Yhteenveto

| Tyyppi | Kuvaus |
|--------|--------|
| Arithmetic | Matemaattiset laskutoimitukset |
| Assignment | Arvojen tallennus ja päivitys |
| Comparison | Palauttaa true tai false |
| Logical | Ehtojen yhdistäminen |

## Yleisimmät operaattorit

| Operaattori | Nimi |
|---|---|
| `+` | Addition (yhteenlasku) |
| `=` | Assignment (sijoitus) |
| `==` | Equality (yhtäsuuruus) |
| `===` | Strict Equality (tiukka yhtäsuuruus) |
| `>` | Greater Than (suurempi kuin) |
| `&&` | Logical AND |
| `\|\|` | Logical OR |
| `!` | Logical NOT |
