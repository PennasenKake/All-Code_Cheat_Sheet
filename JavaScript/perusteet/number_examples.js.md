# number_examples.js

[Näytä alkuperäinen tiedosto GitHubissa](JavaScript/perusteet/number_examples.js)

```javascript
// Peruslaskutoimituksia
let a = 10;
let b = 3;

console.log(a + b); // yhteenlasku
console.log(a - b); // vähennys
console.log(a * b); // kertolasku
console.log(a / b); // jakolasku
console.log(a % b); // jakojäännös

// Muunnos merkkijonoksi
let numeroTekstina = a.toString();
console.log(typeof numeroTekstina); // string
```
