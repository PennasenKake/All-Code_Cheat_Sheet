# string_methods.js

[Näytä alkuperäinen tiedosto GitHubissa](JavaScript/perusteet/string_methods.js)

```javascript
// Merkkijonoja ja niiden käsittelyä
let teksti = "Terve maailma";

// Muutetaan isoiksi kirjaimiksi
console.log(teksti.toUpperCase());

// Pituus
console.log(teksti.length);

// Sisältääkö tietyn sanan?
console.log(teksti.includes("maailma"));

// Leikataan osaa merkkijonosta
console.log(teksti.slice(0, 5));
```
