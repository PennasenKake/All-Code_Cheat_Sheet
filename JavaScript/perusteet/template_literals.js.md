# template_literals.js

[Näytä alkuperäinen tiedosto GitHubissa](https://github.com/PennasenKake/All-Code_Cheat_Sheet/blob/main/JavaScript/perusteet/template_literals.js)

```javascript
// Template literal -merkkijonot

let nimi = "Anna";
let ika = 25;

// Merkkijonojen yhdistäminen perinteisesti
console.log("Hei, nimeni on " + nimi + " ja olen " + ika + " vuotta vanha.");

// Template literalin avulla helppoa ja selkeää
console.log(`Hei, nimeni on ${nimi} ja olen ${ika} vuotta vanha.`);

// Lopullinen merkkijono
let merkkijono = `Hei, nimeni on ${nimi} ja olen ${ika} vuotta vanha.`;
```
